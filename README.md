# 💼 Bonolo Lekalakala Portfolio

A modern, responsive personal portfolio built with **React**, **Vite**, and **Tailwind CSS** to showcase my skills, projects, education, and experience as a **BSc Informatics student** pursuing opportunities in Software Development, Business Analysis, and Data Analysis.

## 🌐 Live Website

**Portfolio:** https://bml-portfolio.vercel.app

---

## ✨ Features

- Modern and responsive design
- Mobile-friendly layout
- Smooth scrolling navigation
- Downloadable CV
- Featured projects section
- Technical skills showcase
- Education section
- Contact form powered by EmailJS
- GitHub, LinkedIn, Email and WhatsApp integration
- Clean and reusable React components

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/BonoloLekay/Bonolo-Portfolio.git
```

### Navigate into the project

```bash
cd Bonolo-Portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
